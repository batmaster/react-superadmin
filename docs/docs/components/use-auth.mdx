### **React Admin Equivalents**

This hook consolidates multiple React Admin hooks into a single, unified authentication hook:

- **useAuthenticated** → `useAuth` hook
- **useAuthState** → `useAuth` hook
- **useLogin** → `useAuth` hook
- **useLogout** → `useAuth` hook
- **useGetIdentity** → `useAuth` hook

### **Features**

- **Authentication Status**: Check if user is authenticated
- **Login Operations**: Handle user login with various backends
- **Logout Operations**: Handle user logout
- **User Identity**: Get current user information
- **Auth State Management**: Manage authentication state

### **Usage**

```tsx
import { useAuth } from '@react-superadmin/core';

function MyComponent() {
  const { isAuthenticated, user, login, logout, loading, error } = useAuth();

  // Check authentication status
  if (!isAuthenticated) {
    return <LoginForm onLogin={login} />;
  }

  // Access user identity
  return <div>Welcome, {user.name}!</div>;
}
```

### **API Reference**

- `isAuthenticated`: Boolean indicating if user is authenticated
- `user`: Current user object with identity information
- `login(credentials)`: Function to authenticate user
- `logout()`: Function to log out user
- `loading`: Boolean indicating if auth operation is in progress
- `error`: Error object if authentication failed
