# NumberInput

A form component for handling numeric input with step controls, number formatting, and validation.

## Overview

The `NumberInput` component provides enhanced number input functionality with step controls, number formatting, and validation. It supports different number formats including integers, decimals, and currency.

## Basic Usage

```tsx
import { NumberInput } from '@react-superadmin/forms';

function ProductForm() {
  return (
    <NumberInput
      name='price'
      label='Price'
      format='currency'
      currency='USD'
      min={0}
      step={0.01}
      required
    />
  );
}
```

## Number Formatting

The component supports three number formats:

### Integer Format

```tsx
<NumberInput
  name='count'
  format='integer'
  showThousandSeparator={true} // Shows 1,234,567
  showThousandSeparator={false} // Shows 1234567
/>
```

### Decimal Format

```tsx
<NumberInput
  name='percentage'
  format='decimal'
  decimals={2} // Shows 12.34
  decimals={4} // Shows 12.3400
/>
```

### Currency Format

```tsx
<NumberInput
  name='price'
  format='currency'
  currency='USD' // Shows $1,234.56
  currency='EUR' // Shows €1.234,56 (with German locale)
  locale='de-DE' // Uses German formatting
/>
```

## Step Controls

The component includes built-in step controls for incrementing and decrementing values:

```tsx
<NumberInput
  name='quantity'
  showStepControls={true} // Shows up/down buttons
  step={5} // Increment/decrement by 5
  min={0} // Won't go below 0
  max={100} // Won't go above 100
/>
```

### Keyboard Navigation

Users can also use arrow keys to step values:

- `Arrow Up`: Increment by step value
- `Arrow Down`: Decrement by step value

## Validation

The component integrates with form validation systems:

```tsx
<NumberInput
  name='age'
  errors={['Age must be positive']}
  touched={true}
  showValidationErrors={true}
  min={0}
  required
/>
```

## Performance

The component is optimized for performance:

- Uses `useCallback` for event handlers
- Efficient number formatting
- Minimal re-renders
- Debounced input handling

## Best Practices

1. **Always provide a `name` prop** for form integration
2. **Use appropriate `min` and `max` values** to prevent invalid input
3. **Choose the right format** for your use case (integer, decimal, currency)
4. **Provide helpful `helperText`** for complex inputs
5. **Use `step` values** that make sense for your data
6. **Handle validation errors** appropriately
7. **Consider accessibility** when customizing the component
